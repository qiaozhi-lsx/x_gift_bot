FAQ

你可能还想知道

已有 Premium，还能兑换或续期吗？+

本服务通过赠送开通 X Premium，接收账号当前需没有有效的 X Premium 订阅，并通过赠送资格检查。已有订阅无法通过本服务续期或叠加时长。

没有蓝标也不一定符合条件，请以「验证账号」的检查结果为准。近期修改资料或更换登录设备的注意事项，可查看上方「接收账号要求」。

要填写哪个账号？需要密码或验证码吗？+

填写要接收会员的 X 用户名，也就是 @ 后面的部分，不是个人资料上显示的昵称。在本站只需提供卡密和用户名，无需提供密码或短信验证码。每次支持 1～5 张卡密，每张对应一个不同的接收账号，套餐时长以卡密验证结果为准。

点击「验证账号」会检查该账号能否接收赠送。本页检查结果有效期为 5 分钟；超过时间或修改用户名后，按页面提示重新检查，再提交兑换。

验证账号失败，会消耗卡密吗？+

提交兑换前的账号检查不会消耗卡密。请根据提示处理：

  • 未找到账号：核对 X 用户名是否拼写正确，确认没有填写昵称。
  • 暂不能接收赠送：核对账号要求；可换一个符合条件的账号，或待账号符合条件后再验证。
  • 服务繁忙、连接中断或超时：当前资格尚未确认，稍后重试验证即可。

如果已经点击「提交兑换」，请先用「卡密查询」确认原订单状态，再决定下一步。

关闭页面或提交后一直没结果，怎么办？+

成功提交后，关闭页面不会取消后台办理。重新打开本站，在顶部「卡密查询」输入原卡密即可查看状态；批量兑换时逐张查询。

  • 排队中／办理中：继续等待，稍后再次查询，无需重复提交。
  • 待核实：原订单结果尚未确认，请保留卡密并联系购买商家核实。
  • 尚未使用：可返回兑换页核对账号、重新验证后提交。

提交时断网或超时，也应先查询原订单；仅凭页面报错无法判断是否提交成功。

卡密提示未找到、已使用或已停用怎么办？+
  • 格式不正确／未找到：从购买订单重新复制完整卡密，不要遗漏字符；仍无法识别时联系购买商家。
  • 已使用：进入「卡密查询」查看这张卡密的原订单和接收账号信息，无需再次兑换。
  • 已停用，或查询结果与购买情况不符：联系购买商家，提供订单号和查询结果截图。

服务繁忙或查询超时只表示暂时查不到结果，请稍后再查。

显示兑换完成，为什么还没有蓝标？+

先登录填写的接收账号，查看 X 内的 Premium 订阅状态和赠送通知，并按 X 页面提示完成接收步骤。蓝标还需要账号符合 X 的要求并通过审核，兑换完成不代表蓝标会立即显示。

蓝标显示时间以 X 审核结果为准。若接收账号仍没有对应会员，或查询的账号、套餐不符，请联系购买商家，并提供订单号、接收用户名和查询结果截图。查看 X 的蓝标要求 ↗

这是 X 官方网站吗？售后联系谁？+

本站是独立运营的 Premium 赠送兑换服务。卡密、兑换订单和购买售后问题，请通过原购买订单联系商家；X 账号、会员权益及蓝标审核以 X 的规则和处理结果为准。
